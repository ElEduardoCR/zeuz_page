Un poco de ayuda

La primera vez.

Estas versiones todavía no tienen firma comercial. Tu sistema puede mostrar una advertencia al abrirlas. Comprueba que el archivo provenga de esta página o del repositorio oficial de ZEUZ.

Abrir Zeuz Agent en Windows

Ejecuta ZeuzAgent.exe; no requiere instalación. Si SmartScreen muestra “Windows protegió tu PC”, verifica el origen del archivo antes de elegir Más información → Ejecutar de todas formas.

Abrir Zeuz Agent en Mac

Descomprime el ZIP y mueve Zeuz Agent a Aplicaciones. Si macOS bloquea la apertura, revisa la aplicación en Ajustes del Sistema → Privacidad y seguridad y autoriza su apertura únicamente si verificaste su origen.

¿Qué es el archivo SHA-256?

Contiene la huella digital del archivo publicado. Permite comprobar que tu descarga coincide con la versión oficial. No es necesario abrirlo para utilizar Zeuz Agent.
